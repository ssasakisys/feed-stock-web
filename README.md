# Feed Stock Gauge（外部サイト版・ログインなし）

Claudeのアーティファクトを離れ、独立したWebアプリとして動くように作り直したものです。
自分一人だけで使う想定のため、ログイン機能は設けていません。データはクラウド上のデータベース（Supabase）に保存され、PCでもスマホのブラウザでも同じURLを開けば同じデータが見られます。

## 重要な注意（セキュリティについて）

ログインなしのシンプルな構成にしたため、**このアプリのURLとSupabaseのAPIキーを知っていれば誰でもデータを読み書きできます**。
- アプリのURLを他人に教えない・SNS等に載せない
- 心配な場合は、後述の「任意: 簡易パスワード保護」も検討してください

## 使っている技術

- **Next.js**（フロントエンド。Vercelという無料サービスに公開します）
- **Supabase**（無料枠のあるデータベース）

---

## セットアップ手順

### 1. Supabaseプロジェクトを作る

1. https://supabase.com にアクセスし、GitHubアカウント等で登録
2. 「New project」からプロジェクトを作成（リージョンは Tokyo (ap-northeast-1) を推奨）
3. プロジェクトが作成できたら、左メニューの **SQL Editor** を開き、このプロジェクトに含まれる `sql/schema.sql` の中身を貼り付けて実行（テーブルが作成されます）

### 2. 環境変数を設定する

`.env.local.example` を `.env.local` にコピーし、Supabaseの **Settings > API** に表示されている値を貼り付けてください。

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

### 3. ローカルで動作確認（任意）

```
npm install
npm run dev
```

`http://localhost:3000` を開き、農家や商品を追加できるか確認してください。

### 4. Vercelに公開する

1. このプロジェクトのコードをGitHubリポジトリにアップロード
2. https://vercel.com でGitHubアカウントと連携し、そのリポジトリを「Import」
3. 環境変数（`NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`）をVercelの設定画面にも登録
4. デプロイすると `https://your-app.vercel.app` のようなURLが発行されます

デプロイが終われば、PCでもスマホのブラウザでも同じURLを開くだけで、同じデータを見たり編集したりできます。ログイン操作は一切不要です。

## 任意: 簡易パスワード保護を付けたい場合

Vercelの有料プラン（Pro以上）には「Password Protection」という、サイト全体に簡単なパスワードをかけられる機能があります。無料でやりたい場合は、`middleware.js` を追加してBasic認証（ID・パスワードを1組だけ設定）をかける方法もあります。必要であれば実装しますので教えてください。

## 元のClaudeアーティファクト版との違い

- データはクラウドDB（Supabase）に保存され、モバイルのブラウザでもそのまま使えます
- 「クイック記録→コピー→PC側で取り込む」という以前の回避策は不要になりました
- ログイン機能はなし（自分一人だけで使う前提のため）
- ドラッグ&ドロップでの並び替えは、▲▼ボタンによる並び替えに簡略化しています
